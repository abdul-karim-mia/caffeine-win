Live Circular Clock Icon

Visual countdown pie chart right on your taskbar. Dynamic Win32 GDI drawing animates clock hands and color shifts smoothly from Blue to Amber to Red.

Instant Click Cycling

No clunky menus needed. Left-click to step through 15m, 30m, 1h, 2h, 4h, and Indefinite mode. Right-click anytime for direct presets.

Official Win32 Power API

Uses SetThreadExecutionState natively. No simulated keyboard clicks (F15) or artificial mouse movements that disturb your typing or trigger false security alarms.

Microscopic 115 KB Binary

Zero dependencies. Doesn't need .NET Runtime, Visual C++ Redistributable, or Electron. Portable single file you can place anywhere.

Start with Windows

Toggle automatic startup on login directly from the tray menu. Stored cleanly in your user registry without requiring admin privileges.

100% Open Source

Permissive MIT License. Clean Rust codebase with comprehensive unit tests and automated GitHub Actions CI builds.
