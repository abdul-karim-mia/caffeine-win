Frequently Asked Questions

How does Caffeine keep Windows awake without moving the mouse? +
Caffeine calls the official Windows kernel function SetThreadExecutionState with ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED. This informs Windows power management that critical tasks and display activity are active, cleanly resetting idle sleep timers without synthesizing fake keyboard events or jittering mouse inputs.
Does Caffeine for Windows require installation or admin rights? +
No. Caffeine is an ultra-lightweight (~115 KB) standalone portable executable written in pure native Rust with raw Win32 APIs. You can download and run it directly with no installation, no admin privileges, and no .NET or C++ runtime dependencies.
How do I cycle between timer durations? +
Simply left-click the system tray icon to step through the sequence: Off ➔ 15 min ➔ 30 min ➔ 1 hour ➔ 2 hours ➔ 4 hours ➔ Indefinite ➔ Off. You can also right-click the tray icon at any time to select any preset directly or toggle "Start with Windows".
How is this different from PowerToys Awake or old Caffeine utilities? +
PowerToys Awake requires the full .NET 8 runtime and is part of a large ~180MB suite with multiple nested menus. Classic Caffeine (1.98) simulates synthetic F15 keystrokes that can interfere with apps or get flagged by enterprise security software. Caffeine for Windows is under 115 KB, has zero dependencies, uses the official Windows power API, and renders an animated circular clock in your taskbar.
Is Caffeine for Windows safe and open source? +
Yes, 100%. The entire codebase is open source under the permissive MIT License on GitHub. It contains no telemetry, no network calls, and no background services.
