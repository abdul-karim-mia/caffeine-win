Privacy Policy

Caffeine for Windows (Caffeine Win) · Last updated 13 November 2026

Summary: Caffeine for Windows collects nothing. It has no analytics, no telemetry, no crash reporting, and no network code of any kind.

What data the app collects

None. The desktop application does not collect, store, or transmit any personal data. It never connects to the internet: there is no networking code in the binary.

What the app stores on your PC

  • Timer state lives only in memory while the app runs. Closing the app discards it.
  • Microsoft Store builds store your autostart choice in the Windows StartupTask setting, which you control in Settings → Apps → Startup.
  • Installer builds (outside the Store) store the optional "Start with Windows" choice as one per-user registry value (HKCU\Software\Microsoft\Windows\CurrentVersion\Run) that you can remove at any time, and in the app's own menu.

App permissions

The Microsoft Store build requests runFullTrust, the standard permission every packaged desktop app needs to run and to draw its system tray icon. It accesses no files beyond itself, and no network.

This website

The landing page at caffeine-win.vercel.app is static and hosted by Vercel. It makes no database queries and runs no analytics scripts on users. Vercel processes standard server access logs under its own privacy policy.
