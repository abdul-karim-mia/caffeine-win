# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Caffeine for Windows, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Send an email to the project maintainer or report via GitHub Security Advisories tab.
3. Include detailed steps to reproduce the vulnerability.

We will review and respond to reports within 48 hours.
